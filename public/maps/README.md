# Official Frankfurt airport map references

Retrieved 2026-09-06. Original publisher artwork and credits are retained; no geometry has been traced or inferred from these files into the app's 3D model.

- `db-airport-long-distance.pdf`: DB InfraGO, https://www.bahnhof.de/downloads/station-plans/7982.pdf. Edition date not identified. One page with station levels and platforms 4–7.
- `rmv-frankfurt-airport.pdf`: RMV, https://www.rmv.de/c/fileadmin/documents/Stationsplaene/Frankfurt-Flughafen.pdf. January 2024 edition. Pages: long-distance station; Terminal 1 ground transport; regional station concourse and platforms; legend. Historical transport services and Terminal 2 references are not current operating advice.
- Matching PNG files are full-page renders produced with `swift scripts/render-official-maps.swift`. No labels, credits or features are removed.
- Current terminal floor reference is embedded directly from https://map.frankfurt-airport.com/ using the terminal POI links published on Fraport's airport map page. The app does not control the publisher's map, floor selector, or availability.

The 3D interior demo is a generated repeating template and is not validated by these maps. Actual gate locations, amenity coordinates, walkable geometry and travel times have not been imported or verified.
